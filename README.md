# Stereo audio amp

Designed a simple audio amplifier using ICs that I had laying around.
First version only used a single LM386 IC, after testing I realized that I like stereo sound better, thus additional 2 ICs were incorporated.

Works from 5-12V, although you need a clean power supply, or add some decoupling caps to the schematic. 

I just soldered a RC filter on USB cable and it improved the sound by a lot lol
